# kst-tutor-research

Istraživački dnevnik za projekat **„Personalizovano učenje pomoću konverzacionog agenta vođenog teorijom prostora znanja“** (SOTIS).

Ideja u jednoj rečenici: ekspert definiše pojmove kursa i preduslove među njima (KST), a LLM agent kroz razgovor procenjuje šta učenik zna i uči ga onome za šta je spreman (outer fringe, odnosno zona proksimalnog razvoja). Na kraju se rešenje ugrađuje u My Smart Mentor (SHSAT priprema).
